# Project scaffold

Atlas Website currently targets Node.js 22, React 19, Vite 7, Tailwind CSS 3, Hono, tRPC, Drizzle, and MySQL.

Reusable shadcn-style primitives live under `src/components/ui/`; page-specific components belong in `src/components/`, route pages in `src/pages/`, and shared browser utilities in `src/lib/`.

Use `./init.sh` for the verified local quality gate and `README.md` for full-stack, MiniMax smoke-test, and GitHub Pages instructions.
